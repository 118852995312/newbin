## 一、 今日完成工作（已做）

1. **确定输入数据格式与规范**
   - 规范 Contig FASTA 命名规则（多样本支持 `sample:contig` 格式）及 $\ge 1000\text{ bp}$ 过滤阈值；
   - 规范排序比对文件（Sorted BAM）；
   - 对接外部准备好的先验约束数据（`must_link.csv` / `cannot_link.csv`）。

2. **剪除切片（Split）伪造正样本冗余**
   - 彻底删除原 SemiBin 将长 contig 对半切分伪造 must-link 的逻辑；
   - 移除 `must_link_threshold` 长度计算与报错拦截；
   - 移除 `data_split.csv`、`data_split_cov.csv` 等切片计算与磁盘 I/O。

3. **K-mer 序列特征提取优化**
   - 确立 136 维 Canonical 4-mer 特征提取与行归一化；
   - 采用 2-bit 向量化查找表（LUT）大幅加速提取过程，天然过滤非标准碱基。

4. **落地新版 Coverage 特征工程（$2M + 1$ 维）**
   - **均值与方差提取**：各 BAM 流式统计位置级均值 $\mu$ 与方差 $\sigma^2$（去除两端 75 bp 边界效应）；
   - **$2M + 1$ 维特征变换**：
     - **Level（1 维）**：行均值 $\text{mean}(\ln(\mu + \varepsilon))$，表示全局测序水准；
     - **Shape（$M$ 维）**：$\ln(\mu + \varepsilon) - \text{Level}$，抹平拷贝数倍数偏差，行和为 0；
     - **$\log\mathrm{ID}$（$M$ 维）**：离散指数对数 $\ln(\sigma^2 / (\mu + \varepsilon))$，度量内部覆盖均匀性。

5. **流水线收敛与测试验证**
   - 特征矩阵统一收敛输出为 `data.csv`，总维度为 **$136\ (\text{k-mer}) + (2M+1)\ (\text{cov}) = \mathbf{137 + 2M}$ 维**；
   - 编写并跑通 4 样本数值单元测试（`test_kmer_and_cov.py`），验证 9 维结构及偏差消除特性（6 项测试全部通过）。

## 三、 后续工作规划（要做）

### 任务 1：训练数据（约束集）对接与 DataLoader 构建
- 读取已有 `must_link.csv` 与 `cannot_link.csv`，与 `data.csv` 的索引取交集对齐；
- 构建 PyTorch Dataset / DataLoader，设计负样本下采样策略，控制 Batch 内正负对比例（建议 $1:1 \sim 1:3$）。

### 任务 2：深度学习网络结构设计（`NewBinModel`）
- 在 `model.py` 中实现特征提取网络，输入维度为 $137 + 2M$，输出维度为 100 维（`embed_dim=100`）；
- 可采用标准多层感知机（MLP）或 K-mer / Coverage 双分支特征融合网络。

### 任务 3：损失函数与训练循环实现（`train_model`）
- 实现基于先验约束的对比损失（Contrastive Loss / Margin Loss）；
- 编写优化器更新、学习率调整与早停逻辑，训练后导出权重 `model.pt`。

### 任务 4：嵌入推理、聚类与分箱输出
- 使用训练好的模型对全体 contig 推理出 100 维 embedding；
- 联调下游图聚类（Infomap）或密度聚类（DBSCAN），导出最终 Bins FASTA 并评估分箱效果。
