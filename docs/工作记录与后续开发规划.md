### 2. 2026-10-10 完成事项
- **特征构造端追加 Contig 长度（`length`）特征**：流式统计序列长度，在 `main.py` 单/多样本流程中作为最后一列追加至 `data.csv`，定型特征矩阵列数为 **$138 + 2M$ 维**（纯 k-mer 为 137 维）；
- **落地深度双分支特征编码与门控网络（`NewBinModel`）**：
  - k-mer 分支：136 维 $\to 256 \to 64$ 维 $z_{\text{kmer}}$；
  - 长度自适应门控网络 $g(L)$：$\log(1+L) \to \text{Linear} \to \text{Sigmoid}$ 生成自适应权重 $g \in (0, 1)$，调制 $\tilde{z}_{\text{kmer}} = g \cdot z_{\text{kmer}}$，抑制短序列噪声；
  - Coverage 分支：$2M+1$ 维 $\to 64 \to 32$ 维 $z_C$；
  - 特征融合层：拼接 96 维经 $\text{Linear}(96 \to 100)$ 稳定输出 **100 维** 最终嵌入向量；
- **双轨联合损失函数体系实现（`newbin/newbin/loss.py`）**：
  - 主损失 $\mathcal{L}_{\text{main}}$：支持 `ContrastiveHingeLoss`（欧氏边距）与 `SupConLoss`（超球面 InfoNCE）；
  - 共丰度辅助损失 $\mathcal{L}_{\text{co}}$（`CoAbundanceAuxiliaryLoss`）：度量 Coverage 嵌入余弦相似度与对数中心化 Shape 相关系数的 MSE 误差；
  - 核心物理约束与梯度隔离：$\mathcal{L}_{\text{co}}$ 挂在 $Z_C$ 输出端，反向传播严格隔离在 Coverage 编码器内，绝不污染门控网络 $g(L)$ 与 k-mer 编码器。

## 二、 今日工作进展（2026-10-11 完成）

### 1. 训练循环层重构与落地（`train_model`、DataLoader 与动态平衡采样）
- **轻量级成对数据加载器（`PairwiseContigDataset`）**：
  - 采用基于整数索引的延迟映射机制（`idx1, idx2, label`），避免复制高维特征矩阵导致的内存暴涨，单次仅取一对 contig 并在 DataLoader 中批量化。
- **动态负采样与样本平衡策略（`sample_balanced_pairs`）**：
  - **维持 $1:2$ 正负比**：按 $N_{\text{neg}} = 2 \times N_{\text{pos}}$ 目标采样，确保对比学习中负样本的多样性与判别边界清晰；
  - **动态排除已有关联**：在特征库内建立正负关联排除集合，通过全局随机抽样与重试机制构造高质量负样本对；
  - **无约束自监督扰动兜底**：若外部先验 Must-link 完全为空，通过对长 contig 特征添加微小高斯噪声（$\sigma=0.01$）自动构建伪正样本对，确保无外部输入时训练不中断。
- **全功能生产级训练循环（`train_model`）**：
  - **双轨联合损失计算**：前向传播调用 `model(x1, x2, return_zc=True)`，传入 `MetagenomicPipelineLoss` 联合计算 $\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{main}} + \lambda \, \mathcal{L}_{co}$；
  - **优化器与学习率衰减**：配置 `AdamW(weight_decay=1e-4)` 优化器，挂接 `CosineAnnealingLR` 实现平滑退火调度；
  - **数值稳定性保障**：加入梯度裁剪 `clip_grad_norm_(max_norm=5.0)` 防止梯度爆炸；
  - **模型持久化与日志输出**：记录每个 Epoch 的损失分解（`Loss Total / Main / Co`），训练结束自动调用 `save_with_params_to(model_path)` 保存完整的模型权重与网络结构元参数（$M$, `cov_dim`, `out_dim`）。

### 2. 双轨增强图构建与 Leiden 社群切分（`cluster.py` 核心算法落地）
针对高维 k-NN 嵌入图存在的“表观统计盲区”（同一物种内的质粒、前噬菌体、水平转移序列因 GC 异常易脱节，短 contig 判别力受抑），设计并实现了**“双轨增强图 (k-NN 骨架 + 成对 Reads 物理连通) + Leiden 算法”**：

```
┌─────────────────────────────────┐       ┌───────────────────────────────────┐
│     全局语义骨架 (~95%)          │       │     局部物理连通补强 (~5%)         │
│ 100维 L2-Norm Embedding         │       │ 多样本 BAM PE Bridging Reads      │
│ 余弦相似度 Top-k 最近邻图        │       │ MAPQ ≥ 20, 跨 contig 累加计数 C_ij│
└────────────────┬────────────────┘       └─────────────────┬─────────────────┘
                 │                                          │
                 │ A_ij^knn = max(0, cos)                   │ W_pe = α * tanh(C_ij / θ)
                 │                                          │ (截断 C_ij ≥ θ)
                 └───────────────────┬──────────────────────┘
                                     │
                                     ▼
                     ┌───────────────────────────────┐
                     │       双轨图融合矩阵          │
                     │  A_ij = max(A_ij^knn, W_pe)   │
                     │  (强制截断 Cannot-link 边)    │
                     └───────────────┬───────────────┘
                                     │
                                     ▼
                     ┌───────────────────────────────┐
                     │    Leiden 高质量社区划分      │
                     │  (无孤岛/无断连社群分割)      │
                     └───────────────────────────────┘
```

- **PE Bridging Reads 流式解析引擎** (`parse_bam_pe_reads_stream`)：
  - **双引擎跨平台架构**：优先调用系统 `samtools view` 进行快速流式管道解析；若环境缺少 samtools，自动启用基于标准库 `struct` + `zlib` 的纯 Python BGZF 块流式解压与二进制解析器兜底，无需依赖跨平台编译易失败的 `pysam`，内存仅占用数 KB。
  - **严格质控防污染**：过滤未配对、次级比对、重复比对，硬过滤 $\text{MAPQ} < 20$（剔除 rRNA 操纵子等保守多重比对假阳性），仅提取跨越不同 contig 的高置信度物理相邻读段。
- **跨样本物理连通累加与缓存** (`extract_pe_bridging_links`)：
  - 支持多样本 BAM 跨样本物理连接次数 $C_{ij}$ 累加；
  - 设定阈值截断 $C_{ij} \ge \theta$（默认 $\theta = 3$），过滤偶然测序/比对噪声；
  - 自动缓存与重载 `pe_links.csv`，避免重复扫描巨量比对文件；
  - **自监督衍生价值**：支持提取 $C_{ij} \ge 5$ 且 $\text{MAPQ} \ge 30$ 的超高置信度对，直接导出为天然的 [`pe_must_link.csv`](file:///c:/Users/guqian/Desktop/contig2bin/newbin/newbin/newbin/cluster.py)，反哺自监督对比学习。
- **双轨图融合矩阵** (`build_dual_track_graph`)：
  - **语义骨架**：对 100 维 L2 归一化 Embedding 计算余弦相似度，构建 Top-$k$ 近邻有向/无向对称边，边权 $A_{ij}^{\text{knn}} = \max(0, \cos(z_i, z_j))$；
  - **物理连通注入**：对满足 $C_{ij} \ge \theta$ 的节点对，注入饱和非线性物理边权：
    $$A_{ij} = \max\Big(A_{ij}^{\text{knn}},\ \alpha_{\text{pe}} \cdot \tanh\big(\frac{C_{ij}}{\theta}\big)\Big)$$
    默认 $\alpha_{\text{pe}} = 0.9, \theta = 3.0$。物理强连接能够在图结构上直接将长偏的质粒与短序列拉回宿主基因组社群；
  - **先验约束断边**：强制将 `cannot_link` 先验对的边权置为 0，防止假阳性合并。
- **Leiden 社区划分引擎** (`run_leiden_clustering` / `run_dual_track_leiden`)：
  - 基于 `python-igraph` 底层 C 实现的 `g.community_leiden()`，支持 modularity 目标函数与可调 `resolution`，彻底杜绝旧版 Infomap / Louvain 的社区断连与孤岛碎片问题。
- **历史遗留代码清理**：
  - 彻底清理了旧版无监督 KL 散度（`cal_kl`）、非必要的二次 L1 归一化，以及 `recluster_bins` 中对旧版 `depth_mean` 的错误切片拼接。
